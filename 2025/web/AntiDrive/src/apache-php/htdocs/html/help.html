Guida Utente

Benvenuto! Questo sito ti permette di gestire file e cartelle in modo semplice e intuitivo. Esso è stato elaborato per poter contenere codice, tutorial, ascii arts, e pagine web statiche. Ecco come utilizzare le principali funzionalità:

  • Login: Per iniziare, effettua il login utilizzando il tuo nome utente e la password. Se non hai un account, puoi registrarti cliccando su "Sign-up".
  • Gestione File: Dopo il login, vedrai una barra degli strumenti e un'area di lavoro. Puoi creare nuove cartelle facendo clic con il tasto destro e selezionando "Create-folder" oppure caricare file selezionando "Upload-file".
  • Rinomina e Rimuovi: Per modificare il nome di un file o di una cartella, fai clic con il tasto destro e seleziona "Rename". Per eliminare un elemento, seleziona "Remove".
  • Download: Puoi scaricare i file facendo clic con il tasto destro e selezionando "Download".
  • Navigazione: Per aprire una cartella, fai doppio clic su di essa. Puoi tornare indietro cliccando sulla barra di navigazione in alto.

Ecco alcune informazioni sul comportamento dell'interfaccia:

  • L'interfaccia di rinomina consiste in un campo di input subito sotto l'icona del file, ed è la stessa interfaccia usata per definire il nome di una cartella. Se, mentre si è in questa interfaccia, si clicca il pulsante "esc" viene annullata l'operazione, se invece si preme il tasto "Enter" viene confermata l'operazione.
  • Se, durante l'inserimento del nome di un file o cartella, il nome di quest'ultimo non è valido, il programma fa comparire una schermata sfocata con indicazioni sul formato del nome. Per togliere questa schermata basta fare click su un punto qualsiasi dello schermo. Ma sta attento! se premi il pulsante "esc" uscira dall'inseriemnto del nome comportandosi come al punto precedente.
  • Nello stato attuale dell'applicazione web, si accettano solo file di tipo testuale per esempio file con estenzione ".txt"

Inoltre, puoi effettuare il logout utilizzando il pulsante in alto a sinistra e ricaricare i file della cartella corrente con il pulsante in alto a destra accanto al percorso corrente. Esplora le funzionalità e organizza i tuoi file in modo efficiente. Se hai bisogno di ulteriore aiuto, torna a questa guida.
